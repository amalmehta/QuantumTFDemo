Run it yourself

Reproduce every number

Everything runs on a laptop CPU in Docker. One command reruns all four experiments; two more rebuild the paper and this site from the new results.

1. Build the environment

The image uses TensorFlow Quantum 0.7.6 with TensorFlow 2.18 on Linux and works on any Mac or PC with Docker. It's about 3 GB.

docker build -t quantumtfdemo .

There is also a native route for Intel Macs (TFQ 0.7.2, the last macOS release). It needs a few workarounds, which are listed in docs/INSTRUCTIONS.md.

2. Check it works

Ten tests, about a minute:

docker run --rm -v "$PWD":/work quantumtfdemo python -m pytest -q tests

Every experiment at tiny sizes, about ten minutes:

docker run --rm -v "$PWD":/work quantumtfdemo python -m quantumtf_demo.run_all --preset quick

3. Run the full experiments

A few hours on an 8-core laptop. Results land in results/: every seed, every epoch, the configuration and the library versions.

docker run --rm -v "$PWD":/work quantumtfdemo python -m quantumtf_demo.run_all --preset full

Run a single experiment with --only mnist_qnn, barren_plateaus or noise. The noise experiment reuses the weights saved by mnist_qnn.

4. Rebuild the paper and this site

python paper/figures_scripts/make_all.py paper/arxiv
cd paper/arxiv && tectonic main.tex
python3 site/build_site.py

Every number in the paper is a generated macro, and paper/arxiv/sources.md records where each one comes from. This site reads the same results and the same macros.
