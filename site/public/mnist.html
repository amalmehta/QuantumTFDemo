QNN vs a classical network of the same size

Can 32 trainable angles in a quantum circuit match 37 classical weights on the same pixels?

Not quite. The QNN reaches 86.8% test accuracy and the classical network 90.9%, close to the 91.6% ceiling that the 4×4 input allows.

Results

The classical network is behind after the first epoch, then pulls ahead and stays there with much less spread across seeds. The QNN's loss barely moves after epoch 2. Shaded bands show ±1 standard deviation over 3 seeds; tick "Show each seed" to see the individual runs.

Method
  1. Keep two digits. MNIST 3s and 6s only (1,968 test images).
  2. Shrink to 4×4. Bilinear resize, then drop training images whose small version appears with both labels, leaving 11,520. This happens before binarising, as in the TFQ tutorial.
  3. Binarise. Pixels above 0.5 become 1. Only 193 distinct patterns remain, so a lookup table over them is the best any model can do: 91.6% on the test set.
  4. Encode. Each lit pixel becomes an X gate on its qubit, giving a basis state of 16 qubits.
  5. Train. Each seed draws 3,000 training and 500 test images. Hinge loss on ±1 labels, Adam (learning rate 0.01, batch 32), 4 epochs, exact simulation with adjoint gradients.

Caveats
  • Exact simulation on a CPU: the QNN's training time says nothing about quantum hardware.
  • 3 seeds and two hyperparameter settings tried on seed 0. Treat differences of a point or two with care.
  • The input is so coarse that every model is capped near 91.6%. This task can't show a quantum advantage.
