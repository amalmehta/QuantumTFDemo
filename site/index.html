TensorFlow Quantum · training experiments

Training a quantum neural network on handwritten digits, and where it struggles

A small, reproducible study with TensorFlow Quantum. A 17-qubit circuit learns to tell a 3 from a 6. We compare it with a classical network of the same size, add a classical head, measure how gradients vanish as circuits grow, and train it under simulated hardware noise.

Experiment 1

QNN vs a classical network of the same size

Can 32 trainable angles in a quantum circuit match 37 classical weights on the same pixels?

Experiment 2

Quantum readout vs a classical head

Does reading out every qubit and adding a small dense layer help the same circuit?

Experiment 3

Barren plateaus

How fast do gradients vanish as random circuits get wider and deeper?

Experiment 4

Training under depolarizing noise

How much accuracy does hardware-like noise cost a trained model, and can a model still learn when the noise is there during training?

Run it

Reproduce every number

Docker is the simplest path: it uses TensorFlow Quantum 0.7.6 on Linux and runs on any Mac or PC.

docker build -t quantumtfdemo .

Smoke test (a few minutes), then the full runs used in the paper (a few hours on a laptop CPU):

docker run --rm -v "$PWD":/work quantumtfdemo python -m quantumtf_demo.run_all --preset quick
docker run --rm -v "$PWD":/work quantumtfdemo python -m quantumtf_demo.run_all --preset full

Tests, and rebuilding this page from the new results:

docker run --rm -v "$PWD":/work quantumtfdemo python -m pytest -q tests
python3 site/build_site.py
